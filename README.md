### 🌊 Projet Wave — Exploration de données journalistiques (Wired)
> Projet de fin d'études — Humanités Numériques, Université de Tours

**Stack :** Python · Django · PostgreSQL · ECharts · Railway · Cloudinary

🎯 **Objectif :**  
Construire une application web permettant d'explorer et de visualiser un corpus d'articles du magazine *Wired* (1993–2025).

📌 **Fonctionnalités :**
- 🕸️ **Network graph** des co-occurrences de mots-clés dans les titres
- 🌐 **Radial chart** des top keywords par catégorie
- 🔍 Recherche interactive par mot, auteur, catégorie
- 📰 Panneau d'articles liés aux mots sélectionnés
- 🖼️ Exploration des couvertures par couleur dominante
- 🔥 Heatmap des mots et auteurs par année

🔗 **Application en ligne :**  
👉 https://wave-production-abb3.up.railway.app

🔗 **Dépôt GitHub :**  
👉 https://github.com/kossi-ctrl/Wave
